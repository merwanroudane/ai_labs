# ML Platform — deployment requirements (Streamlit Community Cloud)
#
# Every package here has a manylinux wheel for Python 3.11-3.13, so the
# build is fast and cannot fail on a missing compiler.
#
# TensorFlow is deliberately NOT here. Two reasons:
#   1. the plain `tensorflow` wheel pulls the whole NVIDIA CUDA stack on
#      Linux (several GB) and blows the build disk;
#   2. even `tensorflow-cpu`, which fits, imports at ~500 MB resident --
#      against Streamlit Cloud's 1 GB ceiling the Part II labs would be
#      killed the moment they trained anything.
#
# So the cloud build serves the full course text, every animation and
# every lab that does not need TensorFlow (chapters 1-9, Foundations,
# Mathematics, Autodiff, the checklist, the glossary and the AI Lab).
# Chapters 10-19 keep their lectures, mathematics and animations; their
# labs report that TensorFlow is unavailable and say how to get it.
#
# For the complete platform, including the deep-learning labs:
#     pip install -r requirements-local.txt
